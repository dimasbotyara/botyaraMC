## ✨ Что такое botyaraMC?

**botyaraMC** — это минималистичный, быстрый и уютный лаунчер Minecraft в паре с собственным Python-сервером синхронизации модов и ресурспаков. Создан специально для игры с друзьями по **Radmin VPN**, **Tailscale**, **ZeroTier** или **локальной сети**.

Больше не нужно пересылать архивы со сборкой на 500 МБ в Telegram или Discord каждый раз, когда вы добавили или обновили пару модов:
1. **Хост** настраивает сервер через интерактивный TUI (`python tui.py`) или `config.txt` и просто закидывает `.jar` в `server/mods/` и `.zip` в `server/resourcepacks/`.
2. **Друзья** нажимают **`▶ ИГРАТЬ`** — лаунчер сам находит сервер по UDP, показывает точный объём докачки, докачивает недостающие файлы с поддержкой `HTTP Range`, сверяет `SHA-256`, ставит нужную версию игры, модлоадер и Java, а при включённом `auto_join` сразу закидывает игрока прямо на сервер.

## 🔥 Возможности

### 📦 Умная синхронизация, мульти-серверы и скрытие модов
- **Показ суммарного размера до скачивания** — ещё до запуска кнопка показывает точный объём докачки (например `▶ ИГРАТЬ • Скачать 45 МБ`) и живой прогресс в мегабайтах.
- **Умная докачка (`HTTP Range`) и защита от спама (`Rate Limit`)** — при обрыве соединения `.part`-файлы не пропадают, а докачиваются ровно с места разрыва через `206 Partial Content` с проверкой `SHA-256`. Настраиваемый скользящий лимит запросов по IP (`rate_limit_per_min`, по умолчанию `300/мин`) защищает сервер от спама и автоматически обрабатывается клиентом через `Retry-After`.
- **Несколько серверов в одном лаунчере** — добавляй сколько угодно серверов в `⚙ Настройках` (по IP или через автопоиск в сети) и переключайся между ними в один клик прямо с главного экрана.
- **Изолированные папки сборок (`client_folder`)** — хост может задать имя папки клиента, и сборка аккуратно расположится в `.minecraft/instances/<client_folder>`, продолжая использовать общие `versions/`, `libraries/`, `assets/` и `runtime/` из корневого `.minecraft` без дублирования гигабайтов.
- **Скрытие названий модов (`hide_mods`)** — хочешь сохранить интригу в сборке или спрятать технические моды? Сервер умеет на лету маскировать имена `.jar` под случайные слова (`silent-amber-otter-42.jar`) или криптохэш с секретной солью (`mod_7f3a9c12e4b08d51.jar`) — для всех модов сразу или только выбранных. Прямой запрос по настоящему имени отдаёт `404`.
- **Офлайн-режим по кэшу** — если sync-сервер временно недоступен, игра всё равно запустится по последнему сохранённому манифесту выбранного сервера.

### 🎛️ Двуязычность (`RU` / `EN`) и TUI-конфигуратор
- **Полная поддержка русского и английского языков** — выбор языка вынесен **первым шагом мастера первого запуска** (ещё до ввода ника) и мгновенно переключается в `⚙ Настройках`. На сервере также локализованы комментарии `config.txt`, логи консоли и интерактивный TUI.
- **Интерактивный TUI-скрипт (`server/tui.py`)** на базе `questionary` — настройка всех параметров сервера стрелками в терминале, выбор конкретных `.jar` для скрытия чекбоксами и пошаговый режим `--wizard` с автосохранением.

### ☕ Java, память и тюнинг JVM
- **Автодетект и ручной выбор Java** — сканирует установленные JDK/JRE (Temurin/Adoptium, Zulu, Liberica, GraalVM, Corretto, Oracle, OpenJDK и рантаймы Mojang) на Windows, macOS и Linux с понятной подписью вендора и версии (`Java 21 • Temurin (21.0.4)`), учитывает `java_version` с сервера или сам докачивает официальный рантайм Mojang.
- **JVM-пресеты и редактор флагов** — встроенные профили **`G1GC`**, **`Aikar's Flags`**, **`ZGC`** (автоматически включает `-XX:+ZGenerational` на Java 21–22 и безопасно откатывается на G1GC при Java < 17) и **`Минимальный`**, визуальный редактор собственных пресетов и поле дополнительных параметров JVM.
- **Авто-RAM по системе и ручной выбор** — умный расчёт оптимального объёма памяти через `psutil` без лишних пауз сборщика мусора либо ручной ползунок + точный ввод в МБ.

### 🖥️ Уютный интерфейс и разбор крашей
- **Живые приветствия по времени суток** — 240 тёплых небанальных приветствий для утра, дня, вечера и ночи (на русском и английском), которые автоматически обновляются каждые 10 минут, пока открыт лаунчер.
- **Продуманные мелочи UX**:
  - **5 живых тем оформления** с мгновенной перекраской всех виджетов без перезапуска;
  - **плавная анимация цвета** кнопки `▶ ИГРАТЬ` при наведении и уводе мыши;
  - **чистый главный экран** — полоса прогресса скрыта в простое и появляется только на время синхронизации и запуска;
  - **мгновенное автосохранение** всех изменений в `⚙ Настройках` без лишних кнопок «Сохранить/Отмена»;
  - **строгая валидация ника** (`3–16` символов, только `a-z`, `A-Z`, `0-9` и `_`);
  - **выход из аккаунта и сброс серверов** в один клик (с сохранением всех файлов самого Minecraft).
- **Быстрое открытие папок (`📂 Папки`)** — в один клик или клавишами `1–7` открывает рабочую папку текущей сборки, `mods`, `resourcepacks`, `screenshots`, `crash-reports` и конфиг/логи лаунчера.
- **Таймаут запуска** — отслеживает инициализацию LWJGL/OpenAL и аккуратно останавливает зависший на старте процесс.
- **Краш-репорт-парсер + [mclo.gs](https://mclo.gs/)** — при сбое анализирует `game.log`, `crash-reports/crash-*.txt` и `hs_err_pid*.log` (`OutOfMemoryError`, несовпадение версии Java, конфликт модов Fabric/Forge, ошибки Mixin, сбои драйвера OpenGL/GLFW) и открывает окно лога с кнопками **Скопировать**, **Поделиться (mclo.gs)** (с авто-маскировкой имени пользователя ОС и токенов), **Перезапуск** и **Закрыть**.

## 🧩 Как работают моды, мульти-серверы и папки сборок

`botyaraMC` спроектирован так, чтобы **никогда случайно не удалить** ценные файлы игрока и не качать одни и те же моды заново:

1. **Первый запуск на уже обжитой папке (`mods/old-mods/`)**  
   Если до первого запуска `botyaraMC` в папке `mods/` уже лежали старые моды, отключённые `.disabled`-файлы или подпапки — лаунчер бережно переносит всё прежнее содержимое в `mods/old-mods/`. Ничего не пропадает.
2. **Переключение между серверами без перекачки (`mods/botyaraMC/`)**  
   Когда ты переключаешься с одного сервера на другой, моды, установленные `botyaraMC` для прошлого сервера, не удаляются, а убираются в запасник `mods/botyaraMC/`. Стоит переключиться обратно — лаунчер находит их по `SHA-256` и мгновенно возвращает в `mods/` (`0 Б` по сети!).
3. **Свои клиентские моды (`delete_user_mods`)**  
   - При `delete_user_mods = false` *(по умолчанию)* игрок может спокойно докинуть себе клиентскую миникарту или шейдеры — лаунчер их не тронет.  
   - При `delete_user_mods = true` сервер включает строгий режим сборки и очищает любые сторонние `.jar` в `mods/`.
4. **Ресурспаки (`resourcepacks/`)**  
   Всегда синхронизируются **только на добавление новых** `.zip` с сервера — личные ресурспаки игрока никогда не удаляются и не перезаписываются.

## 🚀 Быстрый старт

### 1. Сервер синхронизации (у хоста)

Сам `server.py` работает на чистом **Python 3.10+** без единой внешней зависимости. Для интерактивного TUI-конфигуратора установи `questionary`:

```bash
cd server
pip install -r requirements.txt   # опционально, для интерактивного tui.py

# Вариант А — настроить сервер через удобное меню в терминале:
python tui.py                     # стрелочное меню (или `python tui.py --wizard` для пошагового мастера)

# Вариант Б — сразу запустить сервер (при первом старте сам создаст config.txt, mods/ и resourcepacks/):
python server.py
```

Не забудь:
- Закинуть моды сборки (`.jar`) в `server/mods/`, а ресурспаки (`.zip`) — в `server/resourcepacks/`.
- Открыть в брандмауэре порты **TCP `25456`** (раздача манифеста и файлов) и **UDP `25457`** (автообнаружение в локальной сети / VPN).
- В `server.properties` самого Minecraft-сервера выставить `online-mode=false` (так как игроки заходят по офлайн-никам).

#### Справочник параметров `server/config.txt`

Все параметры (кроме TCP/UDP портов) перечитываются сервером **автоматически на лету** при сохранении файла или изменении через `tui.py`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `language` | `ru` | Язык консоли сервера, TUI и комментариев в `config.txt` (`ru` / `en`) |
| `server_name` | `botyaraMC Server` | Отображаемое название сервера у игроков в лаунчере |
| `client_folder` | *(пусто)* | Изолированная подпапка сборки внутри `.minecraft/instances/<имя>` (пусто = корень `.minecraft`) |
| `http_port` | `25456` | TCP-порт HTTP-сервера (`/ping`, `/manifest`, `/mods/*`, `/resourcepacks/*`) |
| `discovery_port` | `25457` | UDP-порт автообнаружения в локальной сети / Radmin VPN |
| `rate_limit_per_min` | `300` | Лимит HTTP-запросов с одного IP в минуту (`0` = выключить лимит) |
| `mc_version` | `1.20.1` | Версия Minecraft, которую лаунчер установит и запустит у клиентов |
| `loader` | `fabric` | Загрузчик модов: `fabric`, `forge`, `neoforge`, `quilt` или `none` (ванилла) |
| `java_version` | `auto` | Требуемая мажорная версия Java (`auto`, `8`, `17`, `21` и т.д.) |
| `delete_user_mods` | `false` | Удалять ли сторонние моды, добавленные игроком вручную (`true` = строгая сборка, `false` = не трогать) |
| `hide_mods` | `none` | Скрытие настоящих имён модов: `none`, `words` (`silent-amber-otter-42.jar`) или `hash` (`mod_7f3a9c12e4b08d51.jar`) |
| `hide_mods_list` | *(пусто)* | Список имён `.jar` через запятую для выборочного скрытия (пусто = скрывать все моды при `hide_mods != none`) |
| `auto_join` | `true` | Автоматически заходить на Minecraft-сервер сразу при запуске игры (`true` / `false`) |
| `minecraft_server` | `127.0.0.1` | IP Minecraft-сервера (`127.0.0.1` / `auto` у удалённых игроков автоматически заменяется на IP sync-сервера!) |
| `minecraft_port` | `25565` | Порт Minecraft-сервера |

### 2. Лаунчер (у игроков)

```bash
cd launcher
pip install -r requirements.txt
python main.py
```

При первом запуске откроется мастер из **4 шагов**:
1. **Язык** (`Русский` / `English`)
2. **Игровой ник** (`3–16` символов: только `a-z`, `A-Z`, `0-9` и `_`)
3. **Тема оформления** (с живым предпросмотром прямо во время выбора)
4. **Сервер синхронизации** (ввод IP или кнопка **«🔍 Найти автоматически»**)

> 💡 **Совет для хоста:** открой `⚙ Настройки` в лаунчере, включи переключатель **«я хост! 👑»** и укажи путь к папке `mods/` своего Minecraft-сервера — тогда при нажатии `▶ ИГРАТЬ` лаунчер будет одновременно синхронизировать моды и в твой клиент, и в папку твоего Minecraft-сервера.

## 🤖 CLI-режим и автоматизация

Запуск без графического интерфейса (Tkinter даже не импортируется) — удобно для ярлыков быстрого запуска, скриптов, безголовых серверов и `systemd`-юнитов:

```bash
cd launcher

# Синхронизировать моды + ресурспаки и сразу запустить игру:
python main.py --play --nick Steve

# Полный кастомный запуск (язык, сервер, Авто-RAM, пресет Aikar, полный экран, авто-отправка краша на mclo.gs):
python main.py --lang ru --play --nick Steve --server 26.12.34.56 --auto-ram --jvm-preset "Aikar's Flags" --fullscreen --share-crash

# Только синхронизировать сборку и подготовить версию MC без запуска окна (работает даже без X11!):
python main.py --sync-only --server 26.12.34.56

# Показать все найденные в системе установки Java:
python main.py --detect-java
```

#### Все флаги CLI

| Флаг | Описание |
|---|---|
| `--play` | Синхронизировать файлы и запустить игру без GUI |
| `--sync-only` | Только синхронизировать моды/ресурспаки и установить версию MC без старта игры |
| `--detect-java` | Вывести список всех найденных в системе установок Java и выйти |
| `--lang {ru,en}` | Язык вывода сообщений и диагностики крашей (`ru` или `en`) |
| `--nick NICK` | Игровой ник (`3–16` символов: `A-Za-z0-9_`) |
| `--server HOST[:PORT]` | Адрес sync-сервера (например `26.12.34.56` или `26.12.34.56:25456`) |
| `--mc-dir PATH` | Путь к базовой папке `.minecraft` |
| `--ram MB` | Выделить фиксированный объём памяти в МБ (например `6144`) |
| `--auto-ram` | Автоматически подобрать объём RAM под систему |
| `--java PATH` | Явный путь к исполняемому файлу `java` |
| `--jvm-preset NAME` | JVM-пресет (`G1GC`, `"Aikar's Flags"`, `ZGC`, `Минимальный` или имя своего пресета) |
| `--jvm-args FLAGS` | Дополнительные флаги JVM |
| `--fullscreen` | Запустить игру в полноэкранном режиме |
| `--resolution WxH` | Запустить игру с заданным размером окна (например `1920x1080`) |
| `--timeout SEC` | Таймаут ожидания инициализации окна в секундах (`0` — отключить) |
| `--no-wait` | Отсоединиться сразу после старта процесса игры |
| `--share-crash` | При аварийном завершении автоматически загрузить лог на `https://mclo.gs` и вывести ссылку |

```ini
WorkingDirectory=%h/botyaraMC/launcher
ExecStart=/usr/bin/python3 main.py --play --nick Steve --auto-ram --share-crash
Restart=on-failure
RestartSec=10

[Install]
WantedBy=default.target
```

При остановке сервиса (`systemctl --user stop botyaramc`) CLI перехватывает `SIGTERM` / `SIGINT` и корректно завершает процесс игры.

</details>

## 🛠 Где хранятся настройки и логи + сборка в `.exe`

Конфигурация лаунчера (`config.json`), учёт модов (`managed.json`), кэши манифестов (`manifest_cache_*.json`) и логи (`launcher.log`, `game.log`, `game.prev.log`) хранятся в стандартной пользовательской директории ОС:

- **Windows:** `%APPDATA%\botyaraMC`
- **Linux:** `~/.config/botyaraMC`
- **macOS:** `~/Library/Application Support/botyaraMC`
- *(Переопределение для портативного режима или тестов: переменная окружения `BOTYARAMC_CONFIG_DIR`)*

<details>
<summary><strong>📦 Сборка лаунчера в один <code>.exe</code> на Windows (PyInstaller)</strong></summary>

```powershell
cd launcher
pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm --onefile --windowed --name botyaraMC `
  --icon icon.ico `
  --add-data "icon.ico;." `
  --add-data "icon.png;." `
  --collect-all customtkinter `
  main.py
```

Готовый файл появится в `launcher/dist/botyaraMC.exe` с правильной иконкой в заголовке окна и на панели задач Windows.

</details>
